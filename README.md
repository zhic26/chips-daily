# 籌碼日報

每個交易日盤後，自動抓證交所、櫃買中心、集保結算所的公開資料，依三大法人買超、千張大戶持股變化與融資增減計分，列出上市、上櫃各 20 檔觀察名單，並追蹤之前的名單後來漲跌如何。

網站內容：
- **大盤體溫**：上市成交金額與 20 日均量、全市場融資餘額增減、外資與投信買賣超、站上季線（60 日均線）的股票比例、漲跌家數，附近 20 日走勢
- **今日名單**：上市、上櫃各 20 檔，分數組成用籌碼圖示呈現，點開看理由與近 5 日明細
- **後續表現**：之前每份名單的隔日與至今漲跌，和同期大盤比較
- **盤後排行**：成交量、週轉率、當沖比率
- 封面的日落賽道動畫是用程式畫的，沒有使用任何照片或影片

網站：<https://zhic26.github.io/chips-daily/>

## 怎麼運作

- `.github/workflows/daily.yml` 會在台北時間週一到週五晚上 22:35 自動執行（融資融券約 21:30 才公布），隔天早上 08:20 再檢查一次有沒有晚到的資料。
- 執行的是 `update.py`：下載資料 → 計算分數 → 產生 `docs/index.html`，再把結果存回這個 repo。
- 網站由 GitHub Pages 直接發布 `docs/` 資料夾。
- 只用 Python 標準函式庫，不用安裝任何套件。

想馬上更新：到 repo 的 **Actions** → **每日更新** → **Run workflow**，日期可以留空。

## 評分方式

| 指標 | 權重 | 算法 |
|---|---|---|
| 法人今日買超 | 25 | 當天三大法人買超 ÷ 5 日均量 |
| 法人 5 日累計 | 25 | 近 5 日法人累計買超 ÷ 5 日總量 |
| 法人買超天數 | 10 | 近 5 日外資買超天數 + 投信買超天數 × 1.5 |
| 千張大戶週增減 | 25 | 千張大戶持股比例週增 1 個百分點以上滿分，減 1 個百分點以上 0 分 |
| 融資減少 | 15 | 當天融資減少張數 ÷ 5 日均量 |
| 籌碼偏重 | 最多 −15 | 近 5 日融資增加 10% 以上扣 5、20% 以上扣 10（至少 300 張）；近 20 日漲 30% 以上扣 5、50% 以上扣 10 |

每一項先在同一個市場內排名換成百分位（0～1）再乘權重。只計普通股、5 日均量 1,000 張以上、股價 10 元以上、當天法人買超的股票；千張大戶持股 99% 以上的不列入。

## 想改設定

改 `config.json` 就好，下次執行就會套用：

- `site.title`：網站名稱
- `top_n`：每個市場取幾檔
- `min_avg_lots`、`min_price`：流動性與股價門檻
- `weights`：五項權重，加起來要等於 100
- `crowding`：籌碼偏重的扣分門檻（融資 5 日增幅、20 日漲幅、扣幾分）

## 資料夾

| 路徑 | 內容 |
|---|---|
| `update.py` | 每日更新的主程式 |
| `chips/` | 下載、解析、計分、產生網頁的程式 |
| `site/template.html` | 網頁版型 |
| `docs/` | 產生出來的網站（GitHub Pages 發布這裡） |
| `data/daily/` | 每個交易日的盤後資料（最近幾天是完整版，更早的只留行情，共約 85 個交易日） |
| `data/picks/` | 每天的名單與排行 |
| `data/tdcc/` | 每週的千張大戶持股 |

## 資料來源

- 臺灣證券交易所：三大法人買賣超、每日收盤行情、融資融券餘額、當日沖銷交易、三大法人買賣金額、公司基本資料
- 證券櫃檯買賣中心：上櫃三大法人、上櫃股票行情、櫃買指數、融資融券餘額、當日沖銷交易、公司基本資料
- 臺灣集中保管結算所：集保戶股權分散表
