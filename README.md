# 籌碼日報

每個交易日盤後，自動抓證交所、櫃買中心、集保結算所的公開資料，依三大法人買超、千張大戶持股變化與融資增減計分，列出上市、上櫃各 20 檔觀察名單，並追蹤之前的名單後來漲跌如何。

網站內容：
- **大盤體溫**：上市成交金額與 20 日均量、全市場融資餘額增減、外資與投信買賣超、站上季線（60 日均線）的股票比例、漲跌家數，附近 20 日走勢
- **今日名單**：上市、上櫃各 20 檔，分數組成用籌碼圖示呈現，點開看理由與近 5 日明細；上方依站上季線比例提醒名單在這種盤的回測表現
- **後續表現**：之前每份名單隔天開盤買進後 5 日、20 日的報酬，和同市場所有合格股票比較
- **盤後排行**：成交量、週轉率、當沖比率
- 封面是 Pexels 免費授權的下曼哈頓天際線縮時影片（電腦版：Sarowar Hussain，手機版：Anatolii Grytsenko），用 `site/make_cover.sh` 剪成無縫循環，放在 `docs/media/`

網站：<https://zhic26.github.io/chips-daily/>

## 怎麼運作

- `.github/workflows/daily.yml` 會在台北時間週一到週五晚上 22:35 自動執行（融資融券約 21:30 才公布），隔天早上 08:20 再檢查一次有沒有晚到的資料。
- 執行的是 `update.py`：下載資料 → 計算分數 → 產生 `docs/index.html`，再把結果存回這個 repo。
- 網站由 GitHub Pages 直接發布 `docs/` 資料夾。
- 只用 Python 標準函式庫，不用安裝任何套件。

想馬上更新：到 repo 的 **Actions** → **每日更新** → **Run workflow**，日期可以留空。

### 版面原則

網頁的順序是：今日名單 → 大盤體溫 → 國際盤勢 → 之前的名單（實盤成績）→ 盤後排行 → 分數怎麼算。名單放最前面；其他都是參考。新的東西只放進現有的區塊（或取代舊的），不再開新區塊；不會影響怎麼用名單、也不會每天看的資訊就不加。

### 大盤體溫

成交金額對 20 日均量、融資增減、外資買賣超、站上季線比例、櫃買指數對加權指數近 20 日的相對強弱（負的代表中小型股比較弱、資金偏向權值股），以及外資在臺股期貨的淨未平倉口數（期交所每天收盤後公布）。舊日子的櫃買指數用月表一次補一個月。只描述，不計分。

### 國際盤勢（只顯示，不計分）

網站上的「國際盤勢」區塊放美國股市、利率、美元與原物料最近一個交易日的收盤：費半、那斯達克、S&P 500、台積電 ADR 溢價、VIX、美國 10 年期公債殖利率、美元指數、新台幣匯率、原油、黃金，加上一段白話說明和接下來的重要事件（Fed 利率會議、美國 CPI、非農就業、台灣央行理監事會）。早上 08:20 那次執行會抓到美股前一晚的收盤，開盤前打開網站就是最新的。

這些數字不放進名單分數：回測裡美股前一晚的漲跌在台股隔天開盤價就反映了（費半當晚漲跌和台股隔天開盤跳空的相關係數 0.63，開盤後到收盤只有 −0.14），而名單是隔天開盤買。費半在 50 日均線上下時，名單的相對表現也沒有穩定的差別。

- 行情來自 Yahoo Finance 的走勢圖介面（非官方，可能改版）。抓不到時沿用上次的數字並註明日期，名單照常更新；格式看起來不對時，執行最後會顯示失敗提醒你。
- Fed 會議日期每週自動從聯準會網站更新；CPI、非農就業和台灣央行的日期寫在 `events.json`，**每年底要補上隔年的日期**（美國勞工統計局 bls.gov/schedule、中央銀行新聞稿「理監事聯席會議預定日期」）。

### 實盤成績

每天公布的名單會在下一個平日早上 9 點開盤前固定存進 `data/track/`，之後模型改版、重算舊名單都不會動到它。網站「之前的名單」區塊最上面會顯示這些名單 5 日、20 日的平均超額報酬（對同市場合格股），跟回測數字放在一起比。滿 20 個交易日的結果會寫回檔案，所以每日資料被清掉後也還在。

### 資料檢查

官方網站改版時，最怕的是程式沒有出錯、卻把錯的數字算進名單。所以每次執行會先檢查：

- **程式自我測試**：`python -m unittest discover -s tests -t .`，用 `tests/fixtures/` 存下的官方網站真實回應確認解析正確，欄位改名或順序變動要能被抓到。每日更新會先跑一次，沒過就不更新。
- **每天的資料**：存檔前檢查筆數（上市約 1,000 檔、上櫃約 800 檔）、收盤價在最高與最低之間、漲跌幅不超過 10%、成交金額 ÷ 成交股數像股價、三大法人「外資＋投信＋自營商＝合計」且不超過成交量、融資融券餘額不是負數。沒過的話這次不更新名單，執行會顯示失敗（GitHub 預設會寄信通知）。
- **名單**：存檔前確認名次從 1 連續排下去、分數在 0～100 且由高到低、沒有重複的股票。
- **一直沒有新資料**：連續超過 8 個平日都抓不到資料（農曆年連假最長約 7 個平日）也算失敗，避免網站改版後每天都被當成休市。
- 注意股、處置股與集保開放資料只影響標籤或備用資料：格式不對時名單照常更新，但執行最後會顯示失敗，提醒去看 `data/meta/last_run.log`。

## 評分方式

| 指標 | 權重 | 算法 |
|---|---|---|
| 法人今日買超 | 10 | 當天三大法人買超 ÷ 5 日均量 |
| 法人 5 日累計 | 10 | 近 5 日法人累計買超 ÷ 5 日總量 |
| 法人買超天數 | 30 | 近 5 日外資買超天數 + 投信買超天數 × 1.5 |
| 千張大戶週增減 | 15 | 千張大戶持股比例週增 1 個百分點以上滿分，減 1 個百分點以上 0 分 |
| 融資 5 日減少 | 15 | 近 5 日融資增減張數 ÷ 5 日均量，減少越多分數越高 |
| 營收成長 | 20 | 最近 3 個月營收比去年同期的成長率（每月 11 日起換用上個月營收） |
| 籌碼偏重 | 只標示 | 近 5 日融資增加 10% 以上（至少 300 張），或近 20 日漲 30% 以上，標上「籌碼偏重」，不扣分 |
| 注意股／處置中 | 只標示 | 當天被證交所、櫃買中心列為注意股標「注意股」（連續被列寫天數，連續被列有可能被處置）；已公布處置、期間還沒結束的標「處置中」，不扣分 |

每一項先在同一個市場內排名換成百分位（0～1）再乘權重。只計普通股、5 日均量 1,000 張以上、股價 10 元以上、當天法人買超的股票；千張大戶持股 99% 以上的不列入。

## 回測

用 2024/10～2026/10 共 494 個交易日回測（照規則每天重選、隔天開盤買進、和同市場所有合格股等權平均比較；千張大戶一項以中間值計算）：

| | 5 個交易日後 | 20 個交易日後 |
|---|---|---|
| 上市名單比同市場 | +0.41% | +1.55% |
| 上櫃名單比同市場 | +0.35% | +1.10% |

- 權重就是依這次回測調的：法人「連續買」是籌碼裡最有預測力的，單日買超張數幾乎沒有；融資看 5 日比看單日好；加入近 3 個月營收成長後，名單明顯變好。
- 試過但沒有加的：當沖比率、短線漲幅、爆量、融券、借券賣出、公司規模（加進分數後名單反而變差或沒差）。
- 2026/10 又試了其他網站常用的做法，也都沒有比較好：中期動能、接近半年高點、短期反轉、營收改成跟同產業比、法人不算自營商、同產業最多 3 檔；估值（本益比、股價淨值比、殖利率）和 ROE 單獨看有一點預測力，但加進名單後 20 日表現反而變差，2025/10 以後 AI 行情裡貴的股票領漲時特別明顯。
- 美股（費半）不放進分數：美股前一晚的漲跌在台股隔天開盤價就反映了，費半強弱時名單的相對表現也沒有穩定差別。
- 名單在多數股票站上季線時比較有效（站上季線超過 5 成：上市名單 5 日平均多 0.61%、20 日多 2.56%），網頁會依當天狀況提醒。
- 籌碼偏重的股票平均報酬沒有比較差，但起伏大，所以改成只標示。
- 差距都不大，一買一賣的成本（證交稅 0.3% 加手續費）就可能吃掉；過去的統計不代表未來。
- 數字存在 `config.json` 的 `backtest`，網頁的盤勢提醒和說明會直接引用。

## 想改設定

改 `config.json` 就好，下次執行就會套用：

- `site.title`：網站名稱
- `top_n`：每個市場取幾檔
- `min_avg_lots`、`min_price`：流動性與股價門檻
- `weights`：六項權重，加起來要等於 100
- `crowding`：籌碼偏重的標示門檻（融資 5 日增幅、20 日漲幅）；`deduct` 設成 `true` 才會扣分

## 資料夾

| 路徑 | 內容 |
|---|---|
| `update.py` | 每日更新的主程式 |
| `chips/` | 下載、解析、計分、產生網頁的程式 |
| `site/template.html` | 網頁版型 |
| `site/make_cover.sh` | 產生封面影片（需要 ffmpeg，平常不用動） |
| `docs/` | 產生出來的網站（GitHub Pages 發布這裡） |
| `data/daily/` | 每個交易日的盤後資料（最近幾天是完整版，更早的只留行情，共約 85 個交易日） |
| `data/picks/` | 每天的名單與排行 |
| `data/tdcc/` | 每週的千張大戶持股 |
| `data/revenue/` | 每月營收（每月 11 日起抓上個月） |
| `data/meta/alerts.json` | 最近的注意股公告與處置股 |
| `data/meta/macro.json` | 國際盤勢（最近的美國行情、ADR 溢價、近期事件） |
| `data/track/` | 實盤名單（開盤前固定，之後不改）與滿 20 個交易日後的結果 |
| `events.json` | 手動維護的事件日期（美國 CPI、非農就業、台灣央行） |
| `tests/` | 自我測試與官方網站回應樣本 |
